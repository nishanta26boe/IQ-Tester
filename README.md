# IQ Tester Using Python

This is a simple IQ Tester made using Python. The program asks multiple-choice questions, checks the answers, and gives the final score along with an estimated IQ.

## Features

* 15 IQ-based questions
* Questions are shown in random order
* Multiple-choice answers (A, B, C, D)
* Calculates the total score
* Gives an estimated IQ score
* Shows an IQ category at the end

## How to Run

Make sure Python is installed on your computer.

Run the program using:

```bash
python main.py
```

Then enter your name and answer each question.

## Modules Used

```python
import time
import random
```

`random` is used to shuffle the questions, and `time` is used for small delays in the program.

## IQ Calculation

The program calculates the IQ using the score obtained in the test. The formula used is a simple scaling formula made for this project.

## Example

```text
Enter your full name: Nishanta Bharali

Q1. What comes next in the series? 2, 4, 8, 16, ?

A) 18
B) 24
C) 32
D) 20

Your answer: C
Correct!
```

At the end, the program displays the score, estimated IQ and category.

## Note

This is a basic Python project made for learning and practice. The IQ score is only an estimate and is **not a certified psychological IQ test**.
