# 1. The Problem

Many people enjoy solving simple IQ and logical reasoning questions, but there is no simple program to practice them and get an instant result. This project solves this by creating a basic IQ test using Python.

# 2. My Project Scope

The project is a command-line based IQ test. It contains multiple-choice questions related to logic, numbers, coding, sequences and reasoning. The program checks the answers, calculates the score and gives an estimated IQ and category.

# 3. Target User

This project is mainly for students and anyone who wants to try a simple IQ and reasoning test.

# 4. Features

- Multiple-choice IQ questions
- Random order of questions
- Checks answers automatically
- Calculates the final score
- Shows estimated IQ
- Displays IQ category
- Simple command-line interface
